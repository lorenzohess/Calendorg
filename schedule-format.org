* Calendorg Timeblock Specification
For an implementation example see [[file:schedule-example.org][schedule-example.org]].
** Files
Two files, one grammar.

| File                               | Owner | Contents                                |
|------------------------------------+-------+-----------------------------------------|
| =$SCHEDULE_DIR/schedule.org=         | you   | commitments, fixed blocks, sleep, types |
| =$SCHEDULE_DIR/calendorg-blocks.org= | app   | allocated blocks                        |

Calendorg reads both but only modifies the second. 
** =schedule.org= 
Four same-level heading sections are required, and each has its own line format for content. Section order does not matter, and anything outside a recognized heading is ignored.
*** Types
The type token =TOKEN= specifies the kind of activity. The color is for visualization.
#+begin_example
- TOKEN #RRGGBB
#+end_example

Adding a type here is all that is needed to make it render.
*** Commitments
A commitment token =TOKEN= specifies an general activity which you want to try to meet target hours =HOURS= for.
#+begin_example
- TOKEN HOURS [#RRGGBB]
#+end_example

=HOURS= is the *total* weekly budget, meetings included. If you add a color, allocated blocks referencing this commitment will render with that color, instead of the default color for allocated blocks.

*** Sleep
Your sleep hours for the entire week. The time window represents an uncertainty range, which is visualized as a gradient.
#+begin_example
- wake HH:MM-HH:MM

#+end_example
** Block grammar
To add a timeblock:
#+begin_example
- DAY HH:MM-HH:MM TYPE [@COMMITMENT[!]] [label]
  : optional comment
#+end_example

- =DAY= is one of =MON TUE WED THU FRI SAT SUN=.
- Times are 24-hour, zero-padded, =HH:MM=.
- =TYPE= is a lowercase token declared under =* Types=.
- =@COMMITMENT= is optional. It names a commitment declared under =* Commitments=, and the block's hours count toward it.
  - The =[!]= suffix to =@COMMITMENT= is optional. It marks a boundary meeting, and hours per commitment are counted between boundary meetings.
- =label= is optional free text to provide timeblock tagging functionality. If no label is given, the commitment is used, or else the type name is used, with hyphens turned into spaces and first character upcased, so =ice-hockey= renders as "Ice hockey".
- A comment is a new line indented and prefixed with =:=.
** Rules
- A block span (including sleep span) must be positive, so a block running past midnight ends at =24:00= or =25:00= rather than wrapping: =WED 21:30-25:00= means 21:30 to 01:00.
- The grid runs 08:00 to 01:00. Times earlier than the grid start belong to the preceding day's column, so a =00:30= block sits at the bottom of the previous day.
- Every block is weekly. No dates appear anywhere in either file.
- Overlapping blocks are legal and will be visually overlapped.
** Parsing
Dispatch on the current heading, then match one regexp per section.
#+begin_src emacs-lisp
(defconst calendorg--re-block
  (concat "^[ \t]*-[ \t]+\\([A-Z]\\{3\\}\\)"
          "[ \t]+\\([0-9]\\{2\\}:[0-9]\\{2\\}\\)-\\([0-9]\\{2\\}:[0-9]\\{2\\}\\)"
          "[ \t]+\\([a-z][a-z-]*\\)"
          "\\(?:[ \t]+@\\([^ \t]+\\)\\)?"
          "\\(?:[ \t]+\\(.*?\\)\\)?[ \t]*$"))

(defconst calendorg--re-comment    "^[ \t]+:[ \t]?\\(.*\\)$")
(defconst calendorg--re-commitment
  "^[ \t]*-[ \t]+\\([^ \t]+\\)[ \t]+\\([0-9]+\\(?:\\.[0-9]+\\)?\\)\\(?:[ \t]+\\(#[0-9a-fA-F]\\{6\\}\\)\\)?[ \t]*$")
(defconst calendorg--re-sleep      "^[ \t]*-[ \t]+\\(wake\\|sleep\\)[ \t]+\\([0-9]\\{2\\}:[0-9]\\{2\\}\\)-\\([0-9]\\{2\\}:[0-9]\\{2\\}\\)[ \t]*$")
(defconst calendorg--re-type       "^[ \t]*-[ \t]+\\([a-z][a-z-]*\\)[ \t]+\\(#[0-9a-fA-F]\\{6\\}\\)[ \t]*$")
#+end_src

Block groups are day, start, end, type, commitment, label, token, hours, color.
** Stats
For each commitment:

- =target= = declared hours − hours of any blocks in your default schedule referencing it
- =allocated= = hours of =allocated= blocks referencing it
- panel shows =allocated / target=
